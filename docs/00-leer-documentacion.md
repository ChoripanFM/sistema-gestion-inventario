# Cómo leer esta documentación

Esta carpeta contiene la documentación técnica del sistema de gestión de inventario.

## Ver los archivos correctamente

Los archivos tienen formato Markdown (`.md`). Para verlos con títulos, listas, tablas, enlaces y bloques de código en Visual Studio Code:

1. Abre cualquier archivo `.md` dentro de la carpeta `docs`.
2. Presiona `Ctrl + Shift + V` para abrir la vista previa.
3. También puedes presionar `Ctrl + K` y después `V` para abrir la vista previa al lado del documento.
4. Para volver al texto fuente, selecciona la pestaña del archivo original.

La vista previa también puede abrirse con clic derecho sobre el archivo y la opción **Open Preview** o **Abrir vista previa**.

## Orden recomendado

Lee los documentos en orden numérico:

1. `01-conceptos.md`: propósito y conceptos principales del sistema.
2. `02-correr-el-proyecto.md`: requisitos, instalación y ejecución.
3. `03-estructura.md`: organización de carpetas y módulos.
4. `04-frontend.md` a `05-diseno-visual.md`: interfaz y criterios visuales.
5. `06-backend.md` a `09-manejo-de-errores.md`: servidor, base de datos, API y errores.
6. `10-imagenes.md` y `11-flujo-ejemplo.md`: manejo de imágenes y recorrido de una operación.
7. `12-integracion-futura.md`: posibles integraciones posteriores.
8. `13-respaldo-de-datos.md`: generación y restauración de respaldos.
9. `14-aplicacion-de-escritorio.md`: empaquetado y ejecución con Electron.

## Qué documento consultar

- Para instalar o iniciar el proyecto: `02-correr-el-proyecto.md`.
- Para encontrar un archivo o entender la organización: `03-estructura.md`.
- Para modificar la interfaz: `04-frontend.md` y `05-diseno-visual.md`.
- Para modificar la API o la lógica del servidor: `06-backend.md` y `08-api.md`.
- Para trabajar con la base de datos: `07-base-de-datos.md`.
- Para solucionar errores: `09-manejo-de-errores.md`.
- Para administrar imágenes: `10-imagenes.md`.
- Para respaldar o restaurar información: `13-respaldo-de-datos.md`.
- Para generar o probar la aplicación instalada: `14-aplicacion-de-escritorio.md`.
